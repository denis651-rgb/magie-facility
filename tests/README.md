# Estrategia de pruebas

- `unit`: lógica de enlace WhatsApp, roles, validaciones de slugs.
- `integration`: acceso a colecciones, permisos y publicación con Postgres temporal.
- `e2e`: navegación, idioma, catálogo, panel y CTA WhatsApp.

Framework y runners: seleccionar tras inicializar la app (por ejemplo Vitest y Playwright).
